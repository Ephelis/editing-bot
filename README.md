# GDR2 프레임 편집기

## 다운로드

- [Windows x64 실행 프로그램 ZIP](https://github.com/Ephelis/editing-bot/raw/refs/heads/main/downloads/GdrFrameEditor-win-x64.zip)
- [C# 소스 코드 ZIP](https://github.com/Ephelis/editing-bot/raw/refs/heads/main/downloads/GdrFrameEditor-source.zip)

ZIP을 다운로드하여 **압축을 모두 풀고 `GdrFrameEditor.exe`를 실행**하세요.
.NET 런타임이 포함되어 있어 별도 설치가 필요 없습니다.
같은 폴더의 `GRIEF.gdr2`가 자동으로 열립니다.

프레임 수정, 선택 입력의 프레임 일괄 이동, 입력 추가·삭제,
P1/P2 및 누름/뗌 변경, 실행 취소·다시 실행, 수정본 저장을 지원합니다.
자세한 사용법은 ZIP 안의 `README.ko.md`를 참고하세요.

원본 파일의 바이트 단위 왕복 검증과 파일 처리 테스트 10개 묶음,
공식 GDR2 C++ 리더 호환성 검증을 통과했습니다.
Windows 실행 파일은 Linux에서 교차 빌드했으며 실제 Windows GUI 실행과 게임 내 재생은 검증하지 못했습니다.

체크섬은 `downloads/SHA256SUMS.txt`에 있습니다.
